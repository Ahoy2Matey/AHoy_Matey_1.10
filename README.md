AHoy Matey is my first C# program and first working chess engine.

## Features

- UCI compatible
- Minimax search
- Alpha-beta pruning
- Simple material evaluation
- Move ordering
- Principal variation reporting

## Current Version

**v1.0** — Latest release

AHoy Matey will continue to grow as new chess-engine features are added and tested.

Why the Name? 
AHoy Matey started out as a mate(y) in 3 puzzle solver and evolved into a full chess engine. The name just stuck.
